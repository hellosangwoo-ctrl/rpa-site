# VI One (브이원)

> VI One(브이원)은 미용실·네일·속눈썹·왁싱·피부·반영구·애견미용처럼 원장님이 시술과 예약·손님 응대를 함께 하는 샵을 위한 예약장부·고객차트 앱입니다. 핵심은 "단골 손님이 계속 오실 수 있게" — 손님마다 다른 재방문 주기를 학습해 평소보다 늦어지는 손님(이탈 전조)과 객단가가 떨어지는 손님을 먼저 알려주고, 예약 전날 확인 문자로 노쇼를 줄입니다. iPhone·iPad(App Store)와 Android(Google Play, 대한민국)에서 받을 수 있고 Starter는 무료입니다. 만든 곳은 서울의 Rigid Point Advisory입니다.

## 핵심 사실

- 이름: VI One (한국어 표기 브이원)
- 대상: 미용실·네일·속눈썹·왁싱·피부·반영구·애견미용 원장님(혼자 또는 소규모로 운영하는 샵)
- 기능: 예약장부(요청→확정→완료·노쇼), 고객차트(메모·사진·방문·결제·소통 이력), VIP·단골·신규·주의 자동 태그, 손님별 재방문 주기 기반 이탈 전조 알림, 객단가 하락 알림, 예약 확인 문자 자동 발송(밤 9시~아침 8시 제외), 간편 매출 기록·카드매출 파일 가져오기, 문자·카카오톡·WhatsApp·인스타 DM 바로 열기, AI 응대 초안(Pro, 보내는 건 원장님), 통화 녹음 파일 업로드 시 AI 요약(Pro)
- 원칙: AI는 매장 FAQ에 있는 내용만 초안으로 쓰고, 모르는 질문은 지어내지 않고 원장님께 넘깁니다
- 플랫폼: iOS(App Store), Android(Google Play, 대한민국). 지원 언어: 한국어·English·Tiếng Việt·日本語·Español
- 요금: Starter 무료. Pro는 월간·연간 구독 — 정확한 금액은 각 스토어에 표시된 가격이 기준입니다
- 데이터: 매장별 분리, 앱 안에서 계정·데이터 삭제 가능, AI 전송 전 개인정보 마스킹
